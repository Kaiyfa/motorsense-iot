Setup

The testbed

EQ-001 is an Elegoo robot car with four DC motors, wheels removed, running at a fixed speed on a bench. A Raspberry Pi reads the sensors, reduces 200 Hz samples to one row per second and posts each row to this application.

SensorWhereMeasures
MPU‑6050On a breadboard resting on the chassisAcceleration; per second the vibration RMS and peak (g) of the 200 Hz samples
INA219In series with the battery packCurrent (A, not calibrated against a reference meter) and pack voltage (V)
DS18B20Not documentedTemperature (°C)

Pipeline

One reading per second travels from the Pi to the dashboard. The scorer is a separate process; the web server never runs the model.

Model inputs

The autoencoder sees three values per second: vibration RMS, vibration peak and current, as sequences of {{ sequence_length }} seconds.

Recorded but not an inputWhy
Pack voltageThe pack state differs between sessions by up to 0.15 V, independent of any fault
TemperatureIt rises 3 to 5 °C per session without reaching a plateau

States, alerts and data

Idle
Current at or below {{ idle_current }} A. Not scored.
Warming up
The first {{ warmup_seconds }} s after the current first exceeds {{ idle_current }} A. Not scored: the model was trained only on data after the warm-up, while vibration is still low and rising during it.
Running
Afterwards. Scored once {{ sequence_length }} consecutive running seconds are buffered. A gap of more than {{ max_gap }} s between readings restarts the state machine; Offline means no reading for more than {{ offline_after }} s.
Alert
Fires on the {{ alert_seconds }}th consecutive second with a score above the threshold (the {{ percentile }}th percentile of scores on the validation session) and stays active while the score stays above it.
Data retention
Raw readings older than {{ retention_days }} days are dropped by the TimescaleDB retention policy that manage.py setup_timescaledb adds. Scores, alerts and maintenance entries are not pruned.

Known limitations

  • Readings travel over plain HTTP without TLS on a home network; the bearer token is sent in clear text.
  • Current is not calibrated against a reference meter; read it as a relative value.
  • Baseline vibration drifts after mechanical handling of the rig (see Negative findings on the Evaluation tab).
  • One fault type was tested: one motor lead disconnected.
  • Small test set: one normal and three fault sessions on one rig, not independent trials.
